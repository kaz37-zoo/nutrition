# 食事・服薬 — Nutrition Tracker

**Version 15.2**  
**更新日: 2026-08-22**

毎日の食事・栄養・薬・サプリを、iPhoneで短時間に記録するためのPWAです。

> 栄養評価は日々の管理を補助する目的です。診断、治療、処方変更の判断には使用しないでください。



## Version 15.2 の主な変更

### Ver.14 UXの復元・再実装

- 今日画面を **食事 / 定期 / 設定** の3サブタブに整理
- 卵・バナナ・りんご・みかん・キウイの個数/本数入力を復元
- 1個/1本あたりのgはユーザーが変更可能。内部ではg換算して栄養計算
- 既存の卵なども、可能なものは個数入力メタデータへ安全に移行
- 食材のドラッグ並び替えを再有効化

### 定期食材の並び替え

定期食材にもドラッググリップを追加しました。押したまま上下へ移動すると `master.weekly` の順序そのものが更新され、再読み込み後も維持されます。

### 食材候補プルダウン

旧実装では候補選択を `touchstart + preventDefault()` で処理していたため、iPhoneで縦スクロールが阻害される可能性がありました。Ver.15.2では通常のクリック選択へ変更し、候補領域には `touch-action: pan-y` と慣性スクロールを設定しています。

### 栄養カードの主従を整理

- **不足 / 過剰 / 充足**を主表示に変更
- 摂取見込みの進捗バーは、不足=赤、注意=橙、判定幅あり=グレー、充足=緑
- 推定範囲は別色の淡い補助領域で **「推定幅」** と明記
- 「目標まで○mg不足」「上限まで○g余裕」など差分を直接表示
- 信頼度は推定幅の補助情報として表示

### 生年月日から年齢を自動計算

プロフィールの手入力年齢を生年月日へ変更しました。誕生日を跨ぐと年齢を自動更新し、栄養基準の年齢区分にも反映します。既存データで生年月日未登録の場合は、登録するまで旧年齢を互換用に保持します。

### 注意書きの位置

「推定を含む判定」の説明は栄養カード上部から外し、栄養タブ最下部の出典・基準注記へ移動しました。

## Version 15.1 の主な変更

### 起動エラーの修正

Ver.15で追加した推定エンジン定数 `V15_QUALITY_CONFIDENCE` を、初回描画が宣言前に参照する可能性があり、Safari等で `Cannot access ... before initialization` が発生する不具合がありました。

Ver.15.1では、推定エンジンの定数・関数がすべて初期化された後に初回描画を開始します。また、初期化エラー時にユーザー設定をデフォルトへ自動上書きする復旧処理を廃止しました。

旧Ver.15の初期化障害で設定がデフォルト保存された特徴的なデータ形を検出した場合のみ、旧保存データと直近の履歴スナップショットから可能な範囲で設定を復旧します。通常データには適用しません。

### 推定グループを階層化・細分化

推定値の母集団を、単純な「野菜」「魚」「肉」から、より近い食品グループへ細分化しました。例：

- 野菜: 葉物 / アブラナ科 / 根菜 / 香味・ねぎ類 / 果菜 / 茎・芽
- 魚介: 青魚 / さけ類 / まぐろ・かつお / 白身魚 / 貝・甲殻類 / いか・たこ
- 肉: 鶏 / 豚 / 牛 / 羊 / 内臓 / 加工肉
- 乳製品: 牛乳・ヨーグルト / チーズ / 乳脂肪
- 果物: 柑橘 / ベリー・ぶどう / りんご・梨 / 熱帯果実・瓜類 / アボカド
- 穀類: 米・もち / パン / 麺 / シリアル・オーツ

細分類の標本数が十分なら細分類を使用し、不足する場合は親分類、それでも不足する場合だけ全食品へフォールバックします。これにより、推定範囲を狭めつつ、少数サンプルによる不安定化を避けます。

遊離糖の「ほぼ0」判定も見直し、パン類や果汁・ジュースを誤って0扱いしないようにしました。

## Version 15 の主な変更

### 推定範囲と5段階判定

栄養データが欠けていても、すぐに「判定保留」にはしません。次の順番で推定します。

1. 確認済みの食品成分値
2. 食品特性から「ほぼ0」と強く推定できる値（`estimated-zero`）
3. 同じ食品群の分布から求めた推定範囲（原則20〜80パーセンタイル、中央値を代表値）
4. それでも推定不能な値は、**実測0ではなく保守推定の下限0**として扱う（`fallback-zero`）

目標に対する表示は次の5段階です。

- **不足** — 推定範囲の上限でも目標に届かない
- **不足気味予測** — 代表推定値は目標未満だが不確実性が残る
- **判定幅あり** — 推定範囲が目標をまたぐ
- **充足気味予測** — 代表推定値は目標以上だが下限は目標未満
- **充足** — 推定範囲の下限でも目標以上

### 栄養素別の信頼度

「データがある食品数 / 食品数」ではなく、**その栄養素への推定寄与度**を使って信頼度を計算します。

そのため、同じ不明食品でも5gしか食べていない場合より300g食べた場合の方が、関連する栄養素の信頼度を大きく下げます。各栄養カードには推定範囲と信頼度を表示します。

今日の不足サマリーも、この推定範囲・5段階判定・信頼度を使って順位付けします。

## Version 14 の主な変更

- 目的表示を白/グレー基調へ変更し、色数と絵文字を削減
- エネルギー目標・タンパク質目標を同じカード内で明示

- 達成率より不足を先に確認できる「不足TOP3」を栄養タブ上部へ追加
- 1位を中央にした表彰台レイアウトで不足率を大きく表示
- 4〜6位もコンパクト表示

### 個数入力

卵・バナナ・りんご・みかん・キウイフルーツは個数/本数で入力できます。

- 卵: 1個=60g
- バナナ: 1本=100g
- りんご: 1個=250g
- みかん: 1個=80g
- キウイフルーツ: 1個=100g

上記は初期値で、実際の大きさに合わせて「1個あたり○g」を変更できます。栄養計算時は最終的なgへ換算します。

### タップ&ドラッグ並び替え

食材行右端のグリップを押したまま上下へドラッグすると、同じ時間帯の中で順番を変更できます。

### 今日タブを3分割

縦スクロールを減らすため、今日画面を次の3つに分けました。

- **食事** — 朝・昼・夕、メニュー、個別食材、薬/サプリ服用操作、手動食事
- **定期** — 週N回/月N回などの定期食材
- **設定** — 薬/サプリ設定、デフォルト食材、食材マスタ、バックアップ

服用期限超過の通知バナーはサブタブ外に置き、どの画面からでも見逃しにくくしています。

## Version 13 で追加した主な機能

### iPhone向けUIを全面整理

- iOSのシステムカラーに近い配色へ変更
- 半透明の固定ボトムタブ
- 主要食材名 17px、セクション見出し 19px、入力欄 16px
- インライン表示で12px未満の文字を廃止
- 主要タップ領域を46〜52px中心に拡大
- iPhone幅では栄養カードを1列表示にして視認性を優先
- 絵文字や技術メモを通常画面から減らし、日常操作を前面に配置
- bottom sheetは上部ハンドル/ヘッダーを下へスワイプして閉じられる

### 食材削除を明確化

食材を削除しようとすると、必ず次のどちらかを選びます。

- **この日だけ外す** — その日だけ一覧と達成率から除外。翌日以降は残る
- **デフォルトから削除** — 毎日の食材設定そのものから削除

その日だけ外した食材は日付欄からまとめて復元できます。

### メニュー機能

複数の既存食材を1つの「メニュー」にまとめられます。

例：

```text
スムージー
├ 冷凍ブルーベリー
├ 牛乳
├ バナナ
└ ヨーグルト
```

- メニューをチェック → 構成食材をすべてチェック
- 構成食材はこれまで通り個別チェック可能
- 個別に全部チェックするとメニュー側も完了表示
- メニュー自体を別の栄養・達成項目として二重計上しない
- メニュー削除時も中の食材は残る

### 薬・サプリを朝 / 昼 / 夕へ統合

薬・サプリはそれぞれタイミングを設定できます。

- 朝 / 昼 / 夕
- 各時間帯の食材の下にまとめて表示
- 時間帯の「すべてチェック」に食材と薬・サプリの両方を含める
- 既存の **飲んだ / 後で / スキップ** は維持
- 通知時刻・スヌーズ・未服用管理も維持
- サプリは「飲んだ」日にだけ栄養値へ加算
- 薬は栄養計算へ加えない

### 食品データを3商品追加

メーカー公式表示を主要栄養値の最優先情報とし、メーカーが公表していない微量栄養素は、原材料・食品形態が最も近い文部科学省FoodDB食品を **Proxy（推定補完）** として登録しています。

- **業務スーパー サラダチキン（冷凍）**
  - メーカー公式: 107 kcal / P 23.2 g / F 1.5 g / 炭水化物 0.1 g / 食塩 1.9 g（100g）
  - 微量栄養素: MEXT 11288「若どり・むね・皮なし・焼き」をProxy
- **タニタ食堂の減塩生みそ なめらか**
  - メーカー公式: 224 kcal / P 9.2 g / F 3.3〜5.5 g / 炭水化物 35.3 g / 食塩 8.3 g（100g）
  - 脂質は表示範囲の中点4.4gを推定値として採用
  - 微量栄養素: MEXT 17045「米みそ・淡色辛みそ」をProxy
- **トップバリュ カットわかめ**
  - メーカー公式（10g）: 14 kcal / P 2.0 g / F 0.5 g / 炭水化物 4.0 g / 糖質 0.1 g / 食物繊維 3.9 g / 食塩 2.1 g / Ca 109 mg
  - アプリDBは100g換算
  - 微量栄養素: MEXT 09040「乾燥わかめ・素干し」をProxy

商品の改訂時は手元のパッケージ表示を優先してください。

## 栄養データの考え方

### `0` と「不明」は別

Version 14でも、測定・確認されていない値を0として扱いません。

品質区分は栄養素ごとに保持します。

- `official` — 文科省FoodDB等で個別確認
- `mext-transform` — MEXT成分表の変換データから安全に補完
- `manufacturer` — メーカー公式値
- `proxy` — 類似食品・類似調理状態からの補完
- `estimated` / `derived` — 推定・計算値
- `legacy` — 旧内蔵DB由来
- `unknown` — 未確認

### 不明値を減らす仕組み

オンライン時、文科省成分表を変換した公開データから、**名称が一意に対応できる食品だけ**不足項目を自動補完します。

- MEXT自動対応候補: 165食品
- 曖昧食品: 34食品
- メーカー商品: 12食品
- 複合料理: 4食品
- サプリ: 5食品
- 内蔵食品合計: 220食品

豚こま、ミックスナッツ、メーカー不明のみそ等のように条件で大きく変わる食品は、誤った値を確定するより未確認/推定のまま残します。

## 栄養基準

公的な目標は厚生労働省「日本人の食事摂取基準（2025年版）」を基礎にしています。

- n-3 / n-6
- B1 / B2 / B6 / B12
- ナイアシン
- 葉酸 / パントテン酸 / ビオチン
- Ca / Mg / P / Fe / Zn / Cu / Mn / K
- ヨウ素 / Se / Cr / Mo
- そのほか主要栄養素

以下は日本のDRIとは分離した参考指標です。

- EPA+DHA: FAO/WHOの成人参考値 0.25 g/日
- 遊離糖: WHO基準
- EPA単独 / DHA単独 / β-カロテン / 総糖類 / 糖質 / 一般成人のプリン体: 独立DRIとして扱わない

詳細は [NUTRITION_AUDIT.md](./NUTRITION_AUDIT.md) を参照してください。

## 保存と移行

データは端末の `localStorage` に保存します。

Version 13は既存データを読み込み、次を追加して移行します。

- `mealGroups` — メニュー
- `hiddenDaily` — 日付ごとの「この日だけ外す」
- 薬・サプリの `slot` — morning / noon / evening

バックアップにはこれらも含まれます。

## 通知

アプリ起動中は、指定時刻、未服用、30分スヌーズを扱えます。

`sw.js` はWeb Push受信に対応しています。PWAを閉じた状態でも予約時刻に確実に通知するには、別途Web Push送信サーバーが必要です。

通常画面では、端末やブラウザの技術的な対応状況メモは表示しません。
