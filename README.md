# 食事・服薬管理アプリ

毎日の食事、栄養素、薬・サプリメントの服用をまとめて管理する、スマートフォン向けのシングルページWebアプリです。

現在は **Nutrition Tracker v11**。将来的にはトレーニング管理AIと統合し、食事・栄養・服薬・サプリ・体組成・トレーニング・回復状態を同じ日付データで扱うことを想定しています。

## 主な機能

### 食事管理

- 朝・昼・夜の定番食材をチェック形式で記録
- 食材の追加・編集・削除・並び替え
- 当日だけ量や内容を変更可能
- その他の食事・外食・料理を手動記録
- お気に入り料理と最近の記録から素早く入力
- 食材マスタの追加・編集
- 毎日 / 曜日指定 / 週N回 / 月N回の頻度管理

### 栄養管理

- カロリー、タンパク質、脂質、食物繊維などを集計
- ビタミン・ミネラル等の摂取状況を確認
- プロフィール・活動量・目的に応じた目標値設定
- 不足栄養素の表示
- 過剰摂取の警告
- 栄養素の推移グラフ
- 日別カレンダー・週間・年間・通算記録

栄養目標・栄養データは、アプリ内で以下を参照元として扱っています。

- 厚生労働省「日本人の食事摂取基準（2025年版）」
- 文部科学省「日本食品標準成分表2020年版（八訂）増補2023年」

## 薬・サプリメント管理

食事とは別のデータとして薬・サプリメントを管理します。

登録項目：

- 種類（薬 / サプリメント）
- 名称
- 1回量
- 予定時刻
- 頻度
- 曜日指定
- メモ
- 通知のON / OFF

当日は次の状態を記録できます。

- **飲んだ** — 服用時刻を記録
- **後で** — 30分スヌーズ
- **スキップ** — その日の服用をスキップ

サプリメントは「飲んだ」と記録した場合のみ、設定された栄養素をその日の栄養計算へ加算します。薬は栄養計算には含めません。

## リマインダー・通知

設定した予定時刻を過ぎても未服用の場合、アプリ内で警告します。

ブラウザの通知許可がある場合はService Workerを利用した通知にも対応しています。

### 通知についての注意

現在の静的Webアプリだけで確実に行えるのは、主に**アプリが動作している間の時刻チェックと通知**です。

アプリを完全に閉じた状態でもサーバー側から指定時刻に通知するには、Web Pushを送信するバックエンドが別途必要です。`sw.js` には将来そのPush通知を受信する処理を用意しています。

## AI連携

AIタブから、現在の食事・栄養状況をChatGPT等へ渡しやすい形式で出力できます。

主な機能：

- 不足栄養素への相談プロンプト
- 今日の食事評価用プロンプト
- 週間傾向分析用プロンプト
- 食事・栄養レポート生成
- AIが返した料理の栄養情報をJSONで取り込み

現時点ではコピー＆ペーストを介した連携です。将来的にはトレーニングAIと共通データを利用する構成を想定しています。

## 記録・分析

- 日別達成状況
- カレンダー表示
- 栄養素の推移グラフ
- 1週間 / 1年 / 通算表示
- ウエスト記録
- ウエストの前回比・推移グラフ

## バックアップ・復元

アプリ内の「データ管理」からJSON形式でバックアップできます。

バックアップ対象：

- 食事設定
- 食事記録
- 薬・サプリ設定
- 服用履歴
- 栄養履歴
- ウエスト記録
- お気に入り
- カスタム食材

機種変更やブラウザデータ削除に備えて、定期的なバックアップを推奨します。

## データ保存について

現在のデータは主にブラウザの `localStorage` に保存されます。

そのため、以下の場合にデータが消える可能性があります。

- ブラウザのサイトデータを削除した場合
- iPhone等でWebサイトデータを消去した場合
- 別のブラウザ・別の端末から開いた場合

クラウド同期は現時点では実装していません。

v11では旧v10 / v8形式の既存データを読み込み、v11形式へ移行する処理を含んでいます。

ビルド工程やnpmパッケージは不要です。

## GitHub Pagesで公開する

1. GitHubで新しいRepositoryを作成します。
2. `index.html`、`sw.js`、`README.md` をRepository直下へアップロードします。
3. Repositoryの **Settings** を開きます。
4. **Pages** を開きます。
5. GitHub Pagesの公開元として対象ブランチを選択します。
6. 公開されたURLへアクセスします。

`index.html` と `sw.js` は**同じ階層**に置いてください。

## iPhoneで使う場合

SafariでGitHub Pagesの公開URLを開き、共有メニューからホーム画面へ追加すると、日常的にアプリのように起動できます。

通知を利用する場合は、アプリ内の「通知を設定」から通知許可を行ってください。

## ローカルで動作確認する場合

Service Workerは通常、`file://` でHTMLを直接開いただけでは正常に登録できません。

通知を含めて確認する場合は、localhostで簡易HTTPサーバーを起動してください。

Pythonが入っている環境なら、Repositoryのフォルダで次を実行できます。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 注意事項

このアプリの栄養評価、目標値、AIによる提案は健康管理を補助するための情報です。医療上の診断や治療、処方内容の変更を行うものではありません。
